Methodology

Did you know words can be expressed mathematically? As a human, you intuitively know that words like “king” and “queen” are alike.

By playing billions of guessing games, machine learning algorithms can calculate this, too.

king−man+woman=queen

This is a data science method called text embedding. Imagine a table like the one below.

KingQueenPrince
Nobility0.980.970.85
Gender0.040.960.07
Age0.720.680.21

This table expresses the meaning of words by giving each word a score on different dimensions.

We could use those scores like coordinates to create a three-dimensional space, called meaning-space.

But to capture the meaning of each of the hundreds of thousands of words in the English language, we need many more dimensions.

3dimensions

That is impossible to do by hand, but entirely possible using very large machine learning models. For example, you can make the model play a word substitute game.

The monkey ate the banana.

After each guess, the model is shown the right answer and moves similar words closer together. Over billions of guesses, words begin to form into clusters of meaning. The same trick works for whole passages of text, too.

We don’t have to do this ourselves. Data scientists have made text embedding models publicly available on the internet.

If we have a sufficiently large collection of text, like Hansard and our transcript archives, we can use the model to create a map of meaning.

Once we have these clusters, we can assign each one a label using a method called “coding”.

By mapping topics across hundreds of thousands of passages and millions of words of text, we can begin to identify patterns between different topics and within the same topic.
